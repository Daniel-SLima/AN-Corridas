# Primo 1.0.0 — Como entregar ao motorista

## Instalar

1. Envie o arquivo `Primo_v1.0.0_release.apk` para o celular Android.
2. Abra o arquivo pelo gerenciador de arquivos e permita, se necessário, a instalação de aplicativos dessa origem.
3. Caso já tenha Primo, **instale por cima**. Não desinstale a versão anterior, pois isso pode apagar os registros.
4. Abra o Primo e confira se os registros anteriores e as metas permanecem.

## Começar a usar

- **Corrida:** registre o valor recebido e como recebeu (Dinheiro, Pix, Cartão ou App).
- **Gasolina:** registre o valor do abastecimento.
- **Mecânico:** registre o valor e, opcionalmente, qual serviço foi feito.
- **Metas:** configure os valores para o dia ou a semana.
- **Histórico:** consulte ou corrija registros, por período.
- **Mais → Fechamento financeiro:** veja, baixe ou compartilhe seu CSV.
- **Mais → Aprenda com o Primo:** abra o tutorial do aplicativo ou da bolinha.

## Bolinha flutuante

- Permita que o Primo seja exibido sobre outros aplicativos e ative a bolinha pelo Início.
- Abra o `+` para Corrida, Gasolina ou Mecânico; arraste para uma borda; use `X` para fechar.
- Se desaparecer, reative por **Mais → Bolinha e tela inicial** ou pelo widget.
- Alguns Androids, especialmente Xiaomi/Redmi, podem encerrar serviços em segundo plano.

## Proteger os dados

- Em **Mais → Segurança dos dados → Exportar backup**, salve um JSON regularmente e guarde fora do aparelho.
- **Importar backup substitui os lançamentos existentes**. Exporte uma cópia antes.
- Não desinstale o aplicativo para atualizar.

## Verificação antes da entrega

1. Abra o tutorial do aplicativo, passe por alguns passos e conclua.
2. Faça um registro de corrida fictícia e confirme que aparece no Histórico e no Resumo do dia.
3. Edite ou exclua o registro fictício pelo Histórico.
4. Exporte um backup e confira que o arquivo aparece no local escolhido.
5. Se for usar a bolinha, confirme que abre e registra com o carro parado.

**Privacidade:** o Primo funciona offline; o proprietário é responsável por guardar os arquivos de backup em local seguro.
